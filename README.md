# AshRP03.github.io

Source repository for my personal portfolio website.

The live site presents my background, selected engineering and machine-learning projects, résumé, and professional interests. The website itself is maintained separately from the GitHub profile curation work; this repository contains the HTML, CSS, images, and other assets used to build and publish the site.

## Repository contents

- `index.html` — portfolio landing page
- `projects.html` — project portfolio
- `honors.html` — honors and achievements
- `vision.html` — professional and technical interests
- `studyabroad.html` — study-abroad experience
- `resume.pdf` — résumé artifact
- `css/` — site styles
- `images/` — site assets

## Local preview

Because this is a static site, it can be previewed with any local HTTP server. For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
